Grafo de Base de Datos

Visualización interactiva de las relaciones entre entidades del sistema SIMR

Instrucciones de uso:
  • Selecciona una o más entidades para visualizar
  • Opcionalmente, escribe una consulta de búsqueda con operadores booleanos (AND, OR, NOT)
  • Haz clic en "Generar Grafo"
  • Usa la rueda del mouse para hacer zoom
  • Arrastra los nodos para reorganizarlos
  • Pasa el cursor sobre un nodo para ver información
  • Haz clic en un nodo para ver sus detalles
Operadores de búsqueda:
  • AND - Intersección de términos
  • OR - Unión de términos
  • NOT - Exclusión de términos
  • () - Agrupación de expresiones
